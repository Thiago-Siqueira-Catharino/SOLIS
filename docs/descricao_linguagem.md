## Sobre a lingugem
Nome: solis
Extencao: .sol
Baseando-se em: Java
Inspiracao: Lua
Linguagem compilada e fortemente tipada

## Objetivo da linguagem
Ser uma linguagem para scripts que pode ser integrada
com outras linguagens e inteiramente em portugues brasileiro

## Tipos primitivos:
- String (Linha)
- Int (Inteiro)
- Float (Quebrado)
- Bool (Booleano)
- Void (Vazio)
- List (Lista)

## Paradigma:
POO e funcional

## Operadores matematicos basicos:
adicao: +
multiplicacao: *
subtracao: -
divisao: /
resto: %

## Operadores logicos:
Maior que: > ou {maior}
Menor que: < ou {menor}
Igual: == ou {igual}
Diferenca: != ou {diferente}

## Loops
Enquanto (Equivalente ao while do python)
Para {variavel} em {Iteravel}

Atribucao de variaveis: {Tipo} {variavel} recebe {valor};
Exemplo: Linha x recebe "texto aleatorio";

Condicionais: se/senao
Interrupcao de codigo (ex: loops): pare
